## Postgres schema (drizzle TypeScript)

Names from spec section 5.1. Use `text` for IDs (UUID v7 generated server-side via `uuid` lib, predictable order). Timestamps `timestamp({ withTimezone: true, mode: 'date' })`.

Tables: `users`, `sessions`, `invitations`, `daemons`, `artifacts`, `artifact_versions`, `install_events`, `audit_log`, plus `pairings` (ephemeral, TTL via `expires_at` + sweep job).

`invitations` schema:
```
invitations (
  id UUID PK, token TEXT UNIQUE, email TEXT,
  role TEXT CHECK (role IN ('admin','member')) DEFAULT 'member',
  invited_by_user_id UUID FK,
  expires_at TIMESTAMPTZ,
  redeemed_at TIMESTAMPTZ,
  redeemed_by_user_id UUID FK,
  created_at TIMESTAMPTZ
)
```
Tokens are 256-bit random, single-use, default TTL 7 days. Admin can revoke (set `expires_at = now()`).

All migrations in `ops/migrations/` numbered `0001_init.sql`, `0002_*.sql`, …

## WSS message protocol

Endpoint: `wss://<host>/ws`
Auth header: `Authorization: Bearer <token>` (session_token pro browser, device_token pro daemon).

Wire format: JSON, line-delimited (`{"type":"...","payload":{...},"id":"..."}`). `id` korelace request/response.

**Daemon → Hub:**
- `inventory.snapshot` — kompletní inventory na connect
- `inventory.delta` — change event (added/removed/modified)
- `job.result` — výsledek `install`/`enable`/`disable`/`package` jobu
- `pong`

**Hub → Daemon:**
- `job.install`     `{ artifact_version_id, sha256, download_url }`
- `job.uninstall`   `{ artifact_id }`
- `job.toggle`      `{ artifact_id, slug, enabled: bool }` (jen plugin; non-plugin typy jsou odmítány s `not_supported_in_mvp`)
- `job.package`     `{ slug, type, source_path }` — daemon má zabalit a uploadnout
- `ping`

**Dashboard ↔ Hub (browser session):**
- `subscribe.local`   `{ daemon_id }` — server zařadí browser do broadcast skupiny
- `local.snapshot`    full inventory
- `local.delta`       changes
- `catalog.update`    "new artifact published" broadcast

## TypeScript shared types (`packages/shared-types`)

```ts
export type UUID = string;

export type UserRole = 'admin' | 'member';
export interface UserDTO {
  id: UUID;
  email: string;
  name: string;
  role: UserRole;
  createdAt: string;       // ISO
  lastLoginAt: string | null;
}

export type ArtifactType = 'skill' | 'plugin' | 'command' | 'agent';
export interface ArtifactDTO {
  id: UUID;
  slug: string;
  type: ArtifactType;
  description: string;
  ownerUserId: UUID;
  createdAt: string;
  archivedAt: string | null;
  latestVersion: string | null;
}

export interface ArtifactVersionDTO {
  id: UUID;
  artifactId: UUID;
  version: string;        // semver
  sha256: string;
  manifest: ArtifactManifest;
  publishedByUserId: UUID;
  publishedAt: string;
  deprecated: boolean;
}

export interface ArtifactManifest {
  schemaVersion: 1;
  name: string;           // matches slug
  type: ArtifactType;
  description: string;
  // type-specific fields under typeMeta
  typeMeta: Record<string, unknown>;
}

export type DaemonOS = 'windows' | 'macos' | 'linux';
export interface DaemonDTO {
  id: UUID;
  hostname: string;
  os: DaemonOS;
  agentVersion: string;
  pairedAt: string;
  lastSeenAt: string;
  online: boolean;
}

export interface InventoryItem {
  type: ArtifactType;
  slug: string;
  version: string | null;
  path: string;           // ~/.claude/skills/foo
  enabled: boolean | null; // null kde flag neexistuje
  publishedAs?: { artifactId: UUID; version: string }; // pokud souhlasí s katalogem
}
```

## Naming conventions

- TypeScript: camelCase identifiers, PascalCase types, kebab-case files.
- Go: idiomatic Go, exported PascalCase, files snake_case.
- DB columns: snake_case (drizzle maps snake↔camel).
- API paths: kebab-case in URL, camelCase in JSON bodies.
- Slugs: `[a-z0-9][a-z0-9-]{0,63}` (regex enforced server-side).
- Semver: strict `MAJOR.MINOR.PATCH` (no pre-release in MVP).

## Testing conventions

- Unit tests next to code: `foo.ts` + `foo.test.ts`; Go: `foo_test.go`.
- Integration tests: `apps/<app>/test/integration/`. Use Testcontainers for Postgres + MinIO.
- E2E: `e2e/` at repo root, Playwright.
- Every feature lands with at least one failing test first, then implementation.
- No DB mocks. Unit tests that need DB use Testcontainers.
- CI runs unit + integration on every push; E2E on PR + main.
